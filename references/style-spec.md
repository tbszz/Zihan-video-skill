# 画面规格与可调参数

## 核心逻辑：镜头旋转

- 句与句要连贯：每换一句，镜头**只转一次 90°**，要么向左、要么向右（`turn_mode`：`random` / `alternate` / `left` / `right`），从不多转、不甩圈。
- **转向是整页绕一个固定点刚性旋转**（螺旋相似变换：旋转和缩放用同一个轴心同步进行），不是位置、角度、缩放各插各的值——后者会让旧句像被「扔出去」。新句在转的同时被带进画面；转到一半之前新句在截图卡下层，不会扫过截图卡。
- 转向从新句首字附近的拍点开始（首字前 1 帧到后 4 帧，换段前 3 帧）；快歌拍距比这个窗口还宽时退到半拍（两拍正中）；首字早于转向的会推迟到转向那一帧出现，所以转向前不会闪出横躺的字。转向途中就开始的下一行由转向本身取景，不再插一个中途的镜头键，保证转满 90°。
- 转完后，上一句**竖立**在新句旁边，它的最后一行贴着新句（镜头右转 → 上一句在左边、从下往上读；左转 → 在右边、从上往下读），新句也朝上一句对齐，像一条字链拐了个弯。
- **新句挨着上一句的第一个字开始**：新句第一行和上一句最后一行的第一个字对齐在同一高度。
- **说过的话出屏幕**：镜头只给正在说的这句取景；上一句最多露出 35% 或 80px（`prev_peek` / `prev_peek_px`），通常只剩最后一行贴在画面边缘，不会完整出现在屏幕里。
- 只保留上一句（`keep_prev_groups: 1`），更早的句子直接消失，避免出现倒着的字。
- 组内每出一行，镜头平滑缩放重新取景，所以字块越堆越多、字越来越小。
- **文字有大有小**：每行随机抽一个字号档（`size_classes`：小 0.65 / 中 1.0 / 大 1.5），相邻两行一定不同档，带红词的行更容易抽到大档，再叠加 ±8% 浮动（`size_jitter`）；普通组整体落位大小另有 ±20% 随机（`group_zoom_jitter`）。
- 重点句（`!`）：拆成每行约 4–5 字的大字（5–6 字仍是一行；不在红词、英文单词如 AI 中间断开），从 1.8 倍砸入，关键词用深红，组可放大到 `max_zoom_emphasis`。跟着转向进场的第一行不砸（转向本身就是砸），否则会在横躺时放大成一大片残影。

## 版式：散落（`"layout": "scatter"`）

默认版式是上面的镜头旋转（`chain`）。`scatter` 不转镜头：

- 每句一页，句内按红词边界和停顿切成 2–4 字的小块（`scatter_chunk`；红词、英文单词不拆），跟着口播逐块、逐字出现。
- 每块随机位置、随机大小（`scatter_size` 倍 `base_size`，红词和重点句再放大 1.3–1.6 倍，单字有时特别大），块与块不重叠（`scatter_gap`），离屏幕边 `scatter_margin`。
- 大致从上往下读：同一行的下一块只会出现在上一块右边；一页放不下就翻新页。短句会把行距拉开（最多 `scatter_spread` 倍）铺满画面。
- 下一句开始时上一页整页消失。入字默认在 `pop` / `tumble` / `rise` 中随机；重点句照样砸入。
- 适合配视频背景（见「背景」）。没有转向，`pipeline.py` 不跑 `check_turns.py`。

## 入字效果（每行里逐字出现的方式）

`reveal` 选一种，或 `mix`（默认：每行从 `reveal_mix` 里随机抽一种，按 `seed` 固定，改效果不会动布局）。每个字 4 帧完成（`reveal_frames`），不拖慢转向。

| 效果 | 动法 |
|---|---|
| `waterfall` 瀑布 | 字从上方约 0.7 字高处划落到位，淡入 |
| `flip` 反转 | 字从镜像（背面）绕竖轴翻 180° 转正 |
| `slide` 滑入 | 字从左侧约 0.45 字宽滑入 |
| `tumble` 翻滚 | 字歪着（30–70°）从下方翻进来，落位时回弹一下 |
| `pop` 弹跳 | 字从 0.2 倍弹到原大，略过冲后回弹 |
| `rise` 遮罩上滑 | 字从自己的字框底部滑出来（像从一条缝里升起） |
| `glitch` 故障 | 红/青色错位 + 左右抖动，迅速稳定 |
| `none` 无 | 只有灰→白淡入，不位移 |

重点句砸入时不再叠加左右滑动；瀑布和反转照常叠加。

## 字体和字效

`font` 选预设，或直接写字体文件名/路径（.ttf/.otf，放进 `assets/fonts` 或系统字体目录）。排版按所选字体实测宽度，换字体不会出框。

| 预设 | 文件 | 说明 |
|---|---|---|
| `特黑体`（默认） | Noto Sans SC 900 | 原片风格 |
| `粗黑体` | Noto Sans SC 700 | |
| `细体` | Noto Sans SC 300 | |
| `圆体` | Windows 幼圆 | 本机只有细的一档 |
| `黑体` | Windows 黑体 | |
| `等线` | Windows 等线粗 | |
| `得意黑` | SmileySans-Oblique.ttf | 免费（OFL），需先把文件放进 `assets/fonts` |
| `泼墨`（同 `毛笔`） | 马善政毛笔楷书（assets/fonts） | 毛笔笔触，免费（OFL）；配红字黑底很像书法标题 |
| `龙藏粗楷` | 寒蝉书体·龙藏楷书 特粗（assets/fonts） | 最粗最重的毛笔字，标题压得住，免费（OFL） |
| `志莽行书` | 钟齐志莽行书（assets/fonts） | 笔势飞动的行书，最有「挥墨」感，免费（OFL） |
| `庞门粗书` | 庞门正道粗书体 | 粗壮干脆的书写体，免费商用；不随仓库分发，先跑 `python scripts/get_fonts.py` |

勇敢黑、中秀体、挥墨体是剪映专属字体，只能在剪映里用，拿不到：勇敢黑、中秀体用 `得意黑` / `特黑体` 代替，挥墨体用 `庞门粗书` / `龙藏粗楷` / `志莽行书` 代替。

模板参数对应：「阴影 黑色 不透明度 90」→ `"text_shadow": 0.9`；「描边 黑色」→ `"text_stroke": 3`（世界坐标 px，随镜头缩放）。黑底上阴影几乎看不出，主要在换浅色背景时有用。

## 背景

`background`：

| 值 | 效果 |
|---|---|
| `grid`（默认） | 纯黑 + 40px 深灰网格 |
| `room` | 3D 网格房间：天花板和地板透视网格，线条带淡彩，中间一条黑带；每拍轻微变亮 |
| 视频/图片 | 文件名或路径（.mp4/.mov/.webm/.jpg/.png/.webp），先在项目里找，再到 `assets/backgrounds` 找（`"tree-road"` = `tree-road.mp4`）。视频静音循环、铺满画面，每拍轻微放大；`bg_dim` 盖一层黑（默认 0.15），白字自动加阴影（`text_shadow` 0.6） |

不设 `background` 时，项目里放一个 `bg.mp4` / `bg.jpg` 就自动用它。

模板背景（Pexels 免费可商用，清单在 `assets/backgrounds/backgrounds.json`，视频本体不进仓库）：

```bash
python scripts/get_backgrounds.py            # 全部下载，或写名字只下几个
```

`tree-road` 林荫路行车 / `tree-path` 林荫小路 / `moto-rain` 雨天骑行 / `city-night` 雨夜街道 / `rain-window` 车窗雨滴 / `clouds` 云延时 / `ocean` 海浪俯拍 / `subway` 夜间地铁。下载后统一裁成 720×1280、24fps、≤20 秒、无声。

## 卡点（配乐）

- `beats.py` 用 librosa 测 BPM、拍点、强拍（每 4 拍一个）。
- 有口播：每次镜头转向都从离入字最近的拍点开始；重点句会挪到 ±3 帧内的强拍/拍点上；普通字在 ±1 帧内吸附拍点；每拍镜头轻微弹一下，强拍和重点句弹得更大。
- 纯配乐（`music_only: true`）：每拍出一行，每组从强拍开始转。
- `bgm_offset`（秒）跳过前奏，从音乐的副歌或鼓点开始用。

## 画面元素

| 元素 | 默认值 |
|---|---|
| 画幅 | 720×1280，24fps |
| 背景 | 纯黑 + 40px 深灰网格 |
| 字体 | Noto Sans SC 900（assets/fonts） |
| 白字 / 红字 / 深红 | #FFFFFF / #D0141C / #A00D14 |
| 入字 | 瀑布 / 反转 / 滑入（见上），灰→白，4 帧 |
| 转向 | 每次 90°，整页绕固定点旋转，7 帧缓出 + 轻微运动模糊（≤4px）；换段（空行）同样 90°，10 帧慢进慢出 |
| 截图卡 | 宽 430，顶边在 60% 高度，固定不动，在当前组下层 |
| 封面帧 | `cover` 填了才有，黄字，前 2 帧（给视频号/抖音抓封面） |

## config.json 可调项

所有项都可选，默认值见 `scripts/build_timeline.py` 的 `DEFAULTS`。常用：

```json
{
  "seed": 7,
  "cover": "华为制药\n为啥不造药？",
  "bgm_offset": 12.5,
  "bgm_volume": 0.28,
  "music_only": false,
  "turn_mode": "random",
  "layout": "chain",
  "background": "grid",
  "font": "特黑体",
  "reveal": "mix",
  "reveal_mix": ["waterfall", "flip", "slide"],
  "text_shadow": 0,
  "text_stroke": 0,
  "prev_peek_px": 80,
  "size_classes": [[0.65, 0.3], [1.0, 0.35], [1.5, 0.35]],
  "emphasis_scale": 1.6,
  "group_zoom_jitter": 0.2,
  "colors": { "red": "#D0141C", "deep_red": "#A00D14" }
}
```

想换一种随机布局就改 `seed`。
