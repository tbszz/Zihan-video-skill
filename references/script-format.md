# 稿件格式与写稿规则

## 标记语法（`script.txt`）

| 写法 | 含义 |
|---|---|
| 一行非空文本 | 一个「组」= 镜头转一次 90° 读到的一块字 |
| `/` | 组内换行（每段 2–8 个字最好看） |
| `[词]` 或 `【词】` | 红色关键词 |
| 行首 `!` 或 `！` | 重点句：放大、砸入、关键词用深红；没标 `[ ]` 时整句深红；7 字及以上会自动拆成多行大字（不拆红词和英文单词） |
| 空行 | 换段：下一次仍只转 90°，但转得更慢、更柔和 |
| 行首 `#` | 注释，不显示不朗读 |

逗号、句号等标点只影响 TTS 停顿，画面上会自动去掉。

```
# 示例
很多人做视频/[开头]就输了/前三秒/没人想听你铺垫
!观众只给你[三秒]
所以第一句话/直接给[结论]/再给[证据]

为什么要放[截图]/因为它是/[证据]不是观点
!这话不是我编的
```

## 写稿规则

- 时长 30–60 秒，语速约每秒 6–7 字，总字数 200–380。
- 一组 2–4 行，每组讲完一个小意思，镜头才转。
- 每组最多 1–2 个红词，红词放名词、数字、反转词（「不」「才是」「直接」）。
- 每 3–5 组放一个 `!` 重点句，用来做「卡点」高潮；全片 2–4 个即可，多了就不突出。
- 开头第一组就给冲突或结论；引用信源时用「这话不是我编的 / XX 报道」这类句子，配合下方的截图卡。
- 稿件就是字幕原文：TTS 和对齐都以它为准，改稿要改 `script.txt`。
- 用了外部报道时，在项目 `sources.md` 记下标题、作者/媒体、平台和链接。
